# 👁️ iScan

Sistema de reconocimiento facial desarrollado en Python y OpenCV para identificar personas y registrar entradas y salidas.

## 🚀 Instalación

Instala las dependencias:

```bash
pip install opencv-contrib-python numpy imutils
```

## ▶️ Uso

Ejecuta los scripts en este orden:

```bash
python capturar.py
python entrenar.py
python iscan.py
```

* `capturar.py` → Captura los rostros.
* `entrenar.py` → Entrena el modelo.
* `iscan.py` → Inicia el reconocimiento facial.

## 🛠️ Tecnologías

* Python
* OpenCV
* NumPy
* Imutils
* HTML / Tailwind CSS
